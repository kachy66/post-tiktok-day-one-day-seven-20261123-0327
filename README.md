## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` reads VIDEO.json from the repository root and copies it to the output directory. It refuses the placeholder address the repo ships with: post the video on TikTok from a public account, put its full `https://www.tiktok.com/@<handle>/video/<id>` address in VIDEO.json, and run again.
